# Version 2.0 roadmap teaser

## Requirement: all-playlists promise is explicitly future-facing
AmpDrop Music 1.5 SHALL show the message `Version 2.0 · Import all your playlists` near the import surface.

The message SHALL be presented as a roadmap teaser only. It SHALL NOT claim that bulk cross-provider playlist import is available in 1.5.

### Scenario: user views the 1.5 import surface
- WHEN the canonical 1.5 player renders
- THEN the user can see the 2.0 all-playlists roadmap teaser
- AND current 1.5 import controls remain unchanged and immediately usable.
