    YOUTUBE IMPORTER

    Import playing track + playlist

    Open the track you are listening to, a playlist, or Liked videos on youtube.com, open DevTools → Console, paste the script below, and press Enter. It explicitly captures the current video and then scans the visible list.

    The importer reads metadata already rendered in your browser. Playback uses the visible YouTube player; it does not download or re-host audio.
    DESKTOP PWA

    Use Winamp Music as a Mac app

    Safari on macOS: File → Add to Dock. The site opens as its own standalone app window, keeps the library locally, and contains the YouTube video surface so you can watch or just listen.

    Chrome / Edge: use Install from the address bar or the Install button when it appears.
