    YOUTUBE IMPORTER

    Import playing track + playlist

    Open the track you are listening to, a playlist, or Liked videos on youtube.com. Sign in to YouTube in that browser tab, then run the bookmarklet below. This app does not request Google OAuth or account access; it only reads the current YouTube page you are viewing.

    Browser-only flow: sign in to YouTube, then drag the bookmarklet to your browser bar or copy it and save it as a bookmark. One click on the bookmark imports the current YouTube tab.
    DESKTOP PWA

    Use Winamp Music as a Mac app

    Safari on macOS: File → Add to Dock. The site opens as its own standalone app window, keeps the library locally, and contains the YouTube video surface so you can watch or just listen.

    Chrome / Edge: use Install from the address bar or the Install button when it appears.
