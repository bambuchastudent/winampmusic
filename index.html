    HOW TO USE

    Play YouTube music like a Winamp playlist

    Paste a YouTube track or playlist URL into the YouTube Import field. Winamp Music adds the track or reads the playlist, then keeps your library locally in the browser.

    Use the library search only to filter saved tracks by title, artist, playlist, tag or YouTube ID. Playback, shuffle, share links, Genius lyrics, YouTube comments and Winamp skins continue to work from the same library.

    On iPhone/iPad, add Winamp Music to the Home Screen and import with YouTube → Share → Copy Link → Paste. On Android, the installed PWA can also receive YouTube shares directly. On macOS Safari use File → Add to Dock.

    YOUTUBE IMPORTER

    Import playing track + playlist

    iPhone/iPad: in YouTube tap Share → Copy Link, then use the Paste button in Winamp Music. Android: install Winamp Music, then in YouTube use Share → Winamp Music or paste a link. Desktop: the script/bookmarklet below can capture a rendered YouTube queue.

    Desktop browser flow: sign in to YouTube, then run the importer on the current YouTube tab to capture the visible queue.
    DESKTOP PWA

    Use Winamp Music as a Mac app

    Safari on macOS: File → Add to Dock. The site opens as its own standalone app window, keeps the library locally, and contains the YouTube video surface so you can watch or just listen.

    Chrome / Edge: use Install from the address bar or the Install button when it appears.
